Add to Home Screen

This suite has an app icon and manifest set up. On a plain local file, Android's browser can still add a shortcut with that icon to your home screen — it just won't get the full offline "installed app" treatment browsers reserve for HTTPS sites.

Open the browser's ⋮ menu → Add to Home screen from the Hub tab to get the icon. If you ever push this suite to a GitHub Pages–enabled repo (you already have the tool to do that), reopening it over HTTPS unlocks full install + offline support.
